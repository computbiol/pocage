# Guidelines

1. If a command involves permission limits, sandbox restrictions, or similar execution issues, run it in a persistent terminal.
2. For frontend interaction tasks, use Playwright.
3. Always use Context7 MCP when I need library/API documentation, code generation, setup or configuration steps without me having to explicitly ask.
4. Keep long-running services and iterative debug commands in the same persistent terminal session.
5. Reuse existing persistent terminal sessions when possible to preserve context and logs. Clean up idle persistent terminal sessions promptly.
